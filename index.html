studyplanner 是什么？

学习助手接收你手动发送的资料，整理清单并帮助厘清作业要求。

岗位目标：提取科目、任务、内容和已知截止日期；标记缺失、模糊或冲突的信息。你主动提问时，Agent 可以解释题意并提供开始思路。

Agent 不会自动跟踪课程，也不会代替你联系老师。

能力边界与人工确认

明确说明 Agent 能做什么、不能做什么。

  • 整理用户提供的课程资料，并按已知截止日期排序。
